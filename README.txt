MIKU CLIENT - MINECRAFT 1.20.1

Gereksinimler:
- Java JDK 17
- Gradle
- Minecraft 1.20.1
- Fabric Loader ve Fabric API

DERLEME:
1. Bu klasoru terminalde ac.
2. gradle build komutunu calistir.
3. Basarili olursa build/libs klasorune bak.

Beklenen dosya:
build/libs/MikuClient-1.0.0.jar

LEGACY LAUNCHER:
1. Minecraft 1.20.1 Fabric profilini kur.
2. Fabric API'nin 1.20.1 surumunu indir.
3. Iki mod JAR dosyasini .minecraft/mods klasorune koy.
4. Fabric profiliyle oyunu baslat.

HUD:
- FPS ve koordinatlar
- Sol ve sag tik CPS
- WASD ve Space gostergeleri
- Sag Shift ile HUD ac/kapat

Not: Bu kaynak proje otomatik olarak derlenmis veya test edilmis
degildir. Derleme hatasi olursa hata mesajini kontrol et.
